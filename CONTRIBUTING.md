# Contributing to Nothing App

We're building this to **save human lives**. Contributions from anyone who shares that goal are welcome.

## How to contribute

### Option 1: Suggest an idea or report a bug

1. Go to [Issues](https://github.com/Senortoshi/thenothingapp/issues).
2. Click **New issue**.
3. Describe your idea or the bug.
4. Submit. We'll read it and respond.

### Option 2: Change the code

1. **Fork** this repo (click "Fork" on GitHub so you have your own copy).
2. **Clone** your fork to your computer.
3. **Create a branch** for your work, e.g. `feature/my-feature` or `fix/my-fix`:
   ```bash
   git checkout -b feature/my-feature
   ```
4. Make your changes, then **commit** and **push** to your fork.
5. On GitHub, open a **Pull Request** from your branch to this repo’s `master` branch.
6. We’ll review and merge if it fits the project.

If anything is unclear, open an issue and ask. We’re here to build together.
